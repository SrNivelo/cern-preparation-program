## Objetivo personal

Mi objetivo es desarrollar conocimientos y habilidades en el análisis de datos mediante el trabajo con datasets reales provenientes de experimentos científicos. Busco fortalecer mis conocimientos en programación, comprender nuevas herramientas de análisis y familiarizarme con metodologías utilizadas para trabajar con grandes volúmenes de datos. Además, considero esta experiencia como una oportunidad para ampliar mi formación y prepararme para futuras oportunidades académicas y profesionales.

## Tecnologías y áreas que deseo fortalecer

Python y C++, aplicados al procesamiento y análisis de datos.

ROOT, para familiarizarme con herramientas especializadas en el análisis de datos científicos.

Docker, para mejorar mi manejo de entornos de desarrollo y ejecución.

Análisis y visualización de datos, especialmente en el trabajo con datasets de gran volumen.

Fundamentos de física de partículas, para comprender mejor el contexto de los datos utilizados en el Workshop.
